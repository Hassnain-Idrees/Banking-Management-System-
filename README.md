# Banking Management System

An object‑oriented banking management system designed for my OOP (Object-Oriented Programming) course.  
This project simulates basic banking operations using OOP principles like encapsulation, inheritance, and polymorphism.

---

## 🏦 Features

- Create and manage bank accounts  
- Deposit money into accounts  
- Withdraw money from accounts  
- Check account balance  
- Transaction history (basic)  
- Account search (by account number or name)  

---

## 📐 Architecture & OOP Design

- **Account Class** — represents a bank account with fields like account number, account holder name, and balance.  
- **Transaction Class** — handles transaction details for deposits and withdrawals (if implemented).  
- **Bank / Manager Class** — facilities account management: adding accounts, searching accounts, and handling transactions.  
- Use of **encapsulation** to protect account data.  
- Use of **inheritance / polymorphism** (if you have different account types) to extend the basic account functionality.
